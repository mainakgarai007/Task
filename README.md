# Tasks

Standalone, local-first task automation tool.

### V1
- One-time, hourly, daily, weekly and monthly schedules
- Create, pause, resume, run-now and delete
- Local persistence
- Execution history
- Browser notifications
- Mobile-first dark UI
- GitHub Pages deployment

### Roadmap
Optional AI providers, web monitoring, state-aware change detection, conditions/stop conditions, file processing and event connectors.

AI will be optional; the tool itself does not provide an AI model or API key.

### Development
```bash
npm install
npm run dev
```

### Build
```bash
npm run build
```
